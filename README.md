# Lingourmet Personal Course Lab

Public, browser-only testing page: source text → copy prompt → use your own LLM → paste JSON → validate and preview.

No API key, login, analytics or backend. Source inputs and imported content are not committed or sent to GitHub by the app. External LLM use is manual. The site stores only the most recently saved course in this browser's localStorage, with explicit user action. Download a JSON backup to use in the main app. This lab does not include SRS or official textbook packages.

Static distribution of the shared Lingourmet prompt builder and personal_course.v1 validator. Generated JavaScript has no source map. Format validation does not certify naturalness or CEFR accuracy.
